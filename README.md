# 11:11 — A Little Promise

A five-page, responsive mini-site. The first four pages tell a quiet story about an unexpected friendship and a small promise. The fifth page is intentionally left open for your own letter.

## Preview
Open `index.html` in a browser.

## Add your letter
In `index.html`, find:

```html
<article class="letter-space" aria-label="Your personal letter">
  <!-- Your letter goes here. This space is intentionally empty. -->
</article>
```

Write your own message between the article tags. Use `<p>...</p>` for paragraphs. The earlier pages are already written and intentionally avoid making the confession explicit.

Google Fonts are used when internet is available; fallback fonts keep the page usable offline.
